# 🎮 Wave Defense Mod

Мод для Minecraft 1.20.1 Forge, який додає систему захисту від хвиль мобів з налаштовуваними локаціями, магазином та системою поінтів.

## 📦 Загальна інформація

**Wave Defense** дозволяє адміністраторам створювати локації двох типів:
- **PvE** — хвильовий захист від мобів із магазином, лутом, нагородами та тригерними механіками.
- **PvP** — командні раунди, де гравці б'ються один проти одного.

Гравці входять через клавішу **V** → вибір локації. Адміни в Creative мають доступ до повного редактора через адмін-меню.

---

## 🎮 PvE Локації

| Функція | Опис |
|---------|------|
| **Хвилі мобів** | Кожна хвиля — окремий набір мобів зі своєю кількістю, ростом, шансом та очками. |
| **⚡ Тригерні хвилі** | Хвилі можуть запускатися паралельно основним за певним тригером. Мають налаштування перезарядки (секунди/хвилі). |
| **⚠ Кордон локації** | Відстеження виходу за радіус (1–9999 блоків). Показує таймер повернення; якщо гравець не встиг — автоматична здача. |
| **🌀 Портали** | Поява рандомних порталів біля гравців. Налаштовуються штрафні хвилі та час до відродження порталу. |
| **Авто-активація** | Локація стартує, коли гравець входить у зону. Радіус налаштовується від **5 до 9999 блоків**. |
| **🚀 Тригер запуску** | Локація може автоматично стартувати при спрацюванні обраного тригера для всіх гравців у радіусі. |
| **Магазин** | Категорії: ⚔ Зброя / 🛡 Броня / 🧪 Розхідники / 📦 Інше. Клавіша **B** — відкрити напряму. |
| **Збереження речей** | Речі гравця **завжди** зберігаються і відновлюються після виходу з локації. |

## ⚔ PvP Локації

| Функція | Опис |
|---------|------|
| **Командні раунди** | Налаштована кількість раундів. Перемагає команда з більшістю перемог. |
| **Фаза покупок (BUY)** | Між раундами є час на покупки в магазині. |
| **Спектатор** | Загиблі чекають у спектаторі. Доступна лише кнопка "Здатися". |
| **Статистика K/D/A** | Таблиця вбивств, смертей та асистів між раундами. |
| **Приховані ніки** | Під час активного раунду ніки ворогів приховані, союзники — з зеленими ніками. |

## 📦 Система тригерів (17+)

Кожна точка луту, тригерна хвиля або запуск локації налаштовується через систему тригерів.

| Категорія | Тригер | Опис |
|-----------|--------|------|
| **Загальні** | 🌊 Початок хвилі | При старті кожної нової хвилі. |
| | ⏱ Часові інтервали | Кожні 60 сек, 2 хв або 5 хв. |
| | 🚪 Взаємодія | Відкриття скрині або дверей (PLAYER_OPEN_CHEST/DOOR). |
| **PvE** | ⚔ Вбивство моба | Кожне вбивство моба на локації. |
| | ☠ Стан хвилі | Загибель половини мобів або повне завершення. |
| **PvP** | 🔔 Раунд/Матч | Початок/кінець раунду або матчу, старт фази покупок. |
| | 🔥 Kill streak | Наприклад, 3 фраги підряд одним гравцем. |

## 🔍 Меню та Інтерфейс

- **Пошук** — по локалізованій назві та ID. Поле не скидається при зміні категорії.
- **Підсвічення вибраного** — вибраний предмет або моб обводиться **золотою рамкою**.
- **3D превʼю** — обертова модель предмета або моба зліва від списку.
- **Вкладка ⚙ Спец** — окремий розділ для налаштування кордонів, порталів та тригерів запуску.

## ⚙ Конфіг файл

**Розташування:** `config/wavedefense-common.toml`.

```toml
[general]
  enableHUD = true            # HUD оверлей
  defaultWaveTime = 60        # час між хвилями (сек)
  lobbyTimerSeconds = 30      # таймер лоббі (сек)

[zone_activation]
  radius = 5                  # радіус авто-активації (5-9999)
  particles = true            # коло частинок

[limits]                      # всі від 1 до 9999
  maxWaves = 100              
  maxShopItems = 100          
  maxLootSpawns = 50
```
## 🛠️ Збірка з вихідного коду
```bash
# Клонуйте репозиторій

cd wave-defense-mod

# Зберіть мод
./gradlew build

# JAR файл буде у build/libs/
```
