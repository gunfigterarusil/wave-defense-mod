# 🎮 Wave Defense Mod

Мод для Minecraft 1.20.1 Forge, який додає систему захисту від хвиль мобів з налаштовуваними локаціями, магазином та системою поінтів.

## 📦 Загальна інформація

**Wave Defense** дозволяє адміністраторам створювати локації двох типів:
- **PvE** — хвильовий захист від мобів із магазином, лутом та нагородами
- **PvP** — командні раунди де гравці б'ються один проти одного

Гравці входять через клавішу **V** → вибір локації. Адміни в Creative мають доступ до повного редактора.

---

## 🎮 PvE Локації

| Функція | Опис |
|---------|------|
| **Хвилі мобів** | Кожна хвиля — окремий набір мобів зі своєю кількістю, ростом, шансом та очками |
| **Спорядження мобів** | Броня (4 слоти), зброя (осн./доп. рука), ефекти зілля |
| **Магазин** | Категорії: ⚔ Зброя / 🛡 Броня / 🧪 Розхідники / 📦 Інше. Клавіша **B** — відкрити напряму |
| **Лут-спавн** | Предмети спавняться по тригерах (детально нижче) |
| **Нагороди** | Предмети та поінти за успішне проходження |
| **Авто-активація** | Локація стартує коли гравець фізично входить у зону (радіус налаштовується). Чорне коло з частинок показує межу |
| **Таймер лоббі** | Скидається при кожному новому гравцеві. Коли ніхто новий не заходить — відлік добігає кінця і гра стартує |
| **Стартові поінти** | Сума поінтів що видається при вході для першої покупки |
| **Збереження речей** | Речі гравця **завжди** зберігаються і відновлюються після виходу |

## ⚔ PvP Локації

| Функція | Опис |
|---------|------|
| **Командні раунди** | Налаштована кількість раундів. Перемагає команда з більшістю |
| **Фаза покупок (BUY)** | Між раундами є час на покупки в магазині |
| **Спектатор** | Загиблі чекають у спектаторі. Меню відкривається але доступна **лише кнопка "Здатися"** |
| **Спавн на точку команди** | На початку кожного раунду гравці телепортуються на точку спавну своєї команди |
| **Статистика K/D/A** | Вбивства, смерті, асисти. Таблиця між раундами |
| **Приховані ніки** | Під час активного раунду ніки ворогів не відображаються |
| **Зелені ніки союзників** | Союзники видні з зеленим ніком над головою |
| **Стартові поінти** | Поінти для першої покупки у BUY-фазі |
| **Friendly Fire** | Опціонально вмикається в налаштуваннях |

## 📦 Система лут-спавну

Кожна точка луту налаштовується **незалежно**: своя позиція, предмети (до 4), шанс, кількість та набір тригерів. Один лут-спавн може мати кілька тригерів одночасно.

### Доступні тригери (17):

| Категорія | Тригер | Опис |
|-----------|--------|------|
| **Загальні** | 🌊 Початок хвилі | При старті кожної нової хвилі (дефолт) |
| | ✅ Кінець хвилі | Коли всі моби хвилі знищені |
| | ⏱ Кожні 60 сек | Кожну хвилину |
| | ⏱ Кожні 2 хв | Кожні 2 хвилини |
| | ⏱ Кожні 5 хв | Кожні 5 хвилин |
| | 👤 Гравець приєднався | Коли новий гравець входить на локацію |
| | 💀 Смерть гравця | Коли будь-який гравець помирає |
| **PvE** | ⚔ Вбивство моба | Кожне вбивство моба на локації |
| | ☠ Половина мобів загинула | Коли ~50% хвилі знищено |
| | 🚀 Старт локації | Один раз при запуску |
| | 🏆 Завершення локації | Коли всі хвилі пройдені |
| **PvP** | 🔔 Початок раунду | На старті кожного раунду |
| | 🏁 Кінець раунду | Коли раунд завершується |
| | 🛒 Фаза покупок | На початку BUY-фази |
| | 💣 Команда вибита | Коли вся команда знищена |
| | 🔥 3 фраги підряд | Kill streak 3+ одним гравцем |
| | 🎯 Старт матчу | Один раз на початку матчу |
| | 🏆 Кінець матчу | Після фінального раунду |

> Тригери PvE доступні лише на PvE-локаціях, PvP — лише на PvP. Загальні — скрізь.

## 🔍 Меню вибору предметів та мобів

- **Пошук** — по локалізованій назві та registry ID (наприклад `minecraft:sword`). Поле завжди активне, не скидається при зміні категорії
- **Підсвічення вибраного** — вже-вибраний предмет або моб обводиться **золотою рамкою**. Миттєво видно що вже встановлено
- **3D превʼю** — обертова модель предмета або моба зліва від списку
- **Категорії** — для предметів: Все/Зброя/Броня/Зілля/Їжа/Інше. Для мобів: Все/Летючі/Мерці/Живі/Інші. У дужках — кількість відповідних записів
- **Моддовані** — підтримуються через `ForgeRegistries`, відображається `[modid]`

## ⌨ Гарячі клавіші

| Клавіша | Дія |
|---------|-----|
| **V** | Відкрити головне меню (гравець / адмін) |

## 🧰 Налаштування координат спавну

У редакторі локації є поля X / Y / Z для точки спавну гравців та точок спавну команд (PvP). Якщо поле **порожнє** — використовується поточна позиція адміна. Кнопка **📌** заповнює поля вашою позицією.

## ⚙ Конфіг файл

**Розташування:** `config/wavedefense-common.toml`

```toml
[general]
  enableHUD = true            # HUD оверлей
  defaultWaveTime = 60        # час між хвилями (сек)
  enableUITooltips = true     # підказки в UI
  lobbyTimerSeconds = 30      # таймер лоббі (сек, скидається при новому гравці)

[shop]
  categoriesEnabled = true    # категорії в магазині

[zone_activation]
  radius = 5                  # радіус авто-активації (блоки)
  countdown = 30              # таймер до активації
  particles = true            # коло частинок

[pvp]
  hideEnemyNametags = true    # ховати ніки ворогів
  defaultRounds = 10
  defaultBuyTime = 20

[mob_equipment]
  enabled = true
  armorDropChance = 0.085

[hotkeys]
  shopHotkeyEnabled = true    # клавіша B

[limits]                      # всі від 1 до 9999
  maxMobTypes = 20            # типів мобів у хвилі
  maxWaves = 100              # хвиль у локації
  maxMobSpawns = 50           # точок спавну мобів
  maxPlayerSpawns = 20        # PvP точок спавну
  maxShopItems = 100          # товарів у магазині
  maxLootSpawns = 50          # точок спавну луту
```
