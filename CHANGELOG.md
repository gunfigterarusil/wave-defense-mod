# Wave Defense — Changelog

## v0.2.9 *(поточна)*

**UI/UX:**
* `WaveTriggerEditorScreen`: повністю переписаний:
    * Додано скрол списку тригерів (колесо миші + кнопки ▲▼).
    * Вибір **AND умов**: через Ctrl+клік або повторний клік (додає обов'язкову додаткову умову).
    * Кнопка **"Разово"**: хвиля спрацює лише 1 раз за сесію локації.
    * Поле **"Активувати з хвилі N"**: затримка активації тригерної хвилі до певного етапу.
    * Поле **предмета**: для тригера `PLAYER_HAS_ITEM` тепер можна вказати registry id.
* `LocationEditorScreen`: додана окрема **точка входу** (місце телепортації гравця при авто-активації).
* `WaveConfigScreen`: кнопка тригера тепер візуально відображає параметри `¹` (разово) та `≥N` (активація з хвилі).
* `ShopItemEditorScreen`: нова кнопка **"Тригер доступності"** (відкриває `ShopAvailabilityScreen`).

**Нова логіка:**
* **Портали**: після входу першого гравця діє 30-секундний grace period, після чого портал закривається; повернення гравців у вихідну точку після завершення.
* **PLAYER_HAS_ITEM**: тригер став універсальним (замість жорстко заданих предметів).
* **Тригери магазину**: додано умови появи товарів (`SHOP_WAVE_START`, `SHOP_PLAYER_HAS_ITEM` тощо).
* **Event-driven локації**: тригери `PLAYER_DEATH` та `PLAYER_JOIN` тепер коректно запускають локації через `EventHandler`.

**Виправлення багів:**
* `WaveTrigger MOBS_KILLED_*`: тепер рахує вбивства тільки в межах конкретної локації.
* `MobSelectionScreen`: виправлено рендер мобів (тепер не догори ногами) та точку origin.
* `WaveManager`: тригерні хвилі тепер коректно перевіряють умови AND, `oneTimeOnly` та `activateFromWave`.
* `WaveTriggerEditorScreen`: виправлено дублікат поля `triggerScrollOffset` та порожні tooltips.
* `LocationEditorScreen.getLocTip()`: додано описи для всіх ключових кнопок.

## v0.2.8

**Виправлення помилок:**
* `AdminMenuScreen`: виправлено краш при відкритті та скролі через заміну константи `ITEMS_PER_PAGE` на поле `itemsPerPage`.
* `WaveManager`: виправлено сумісність з MC 1.20.1 (метод `getFreeSlot()` тепер порівнює `int != -1`).
* `WaveManager`: виправлено структуру коду (прибрано зайву `}`, що виносила методи за межі класу).
* `EventHandler`: додано `@SubscribeEvent` для тригерів `PLAYER_OPEN_CHEST` та `PLAYER_OPEN_DOOR`.
* Додано відсутні імпорти (`WaveTrigger`) та метод `fireWaveTriggerForPlayer()`.

## v0.2.7

**Нові функції:**
* **⚠ Кордон локації**: налаштування радіусу (1–9999 блоків) з попередженням та авто-здачею при виході.
* **⚡ Тригерні хвилі**: паралельний запуск хвиль, що не порушує основний порядок; налаштування перезарядки.
* **🌀 Рандомні портали**: динамічна поява порталів біля гравців; штрафні хвилі за ігнорування.
* **📍 Радіус авто-активації**: розширено діапазон значень (5–9999 блоків) з точним введенням.
* **⚙ Вкладка Спец**: централізоване меню для нових налаштувань у редакторі локації.
