# 📋 Повний Патчлог — Wave Defense Mod (v0.2.10)

Цей документ містить детальний опис усіх змін, виправлень та нових функцій, впроваджених у процесі розробки від версії v0.2.3 до v0.2.10.

---

## [v0.2.10] — Імпорт/Експорт та критичні виправлення тригерів
### ⚡ Виправлення логіки тригерів хвиль
- **Покращений спавн**: Тригерні хвилі більше не спавняться автоматично по черзі — вони запускаються **виключно** при виконанні умови тригера.
- **Точність лічильників**: 
    - Тригер `WAVE_COMPLETE` тепер спрацьовує миттєво через системну подію.
    - `MOBS_KILLED_*` тепер коректно рахує вбитих мобів окремо для кожної локації (скидається при старті/здачі).
- **Режим "Разово" (oneTimeOnly)**: Скидається лише після повного завершення сесії локації.
- **Таймери та Зони**: Тригери `TIMER_60/120/300` тепер запускають і тригерні хвилі. Тригер `PLAYER_ENTER_ZONE` для хвиль тепер перевіряє наявність гравців всередині локації.
- **Кулдаун**: Встановлено мінімальний кулдаун у 5 секунд для всіх тригерів (навіть у режимі `NONE`).

### 🖥️ GUI та UI/UX покращення
- **Захист від видалення**: Впроваджено систему підтвердження видалення локації (кнопка `✕` -> підсвічування `✓ ТАК` -> підтвердження).
- **Виправлення відображення**:
    - Підказки (tooltips) для авто-активації та збереження речей тепер рендеряться поверх усіх елементів.
    - Моби у меню вибору тепер мають правильний нахил та вертикальне положення.
    - В меню точок луту координати зміщено вниз, щоб не перекривати слоти предметів.
- **Зручність вводу**: Додано кнопку "✋" поруч із полем ID предмета — вона автоматично вставляє registry id предмета з руки гравця.

### 📤 Нові функції та техчастина
- **Імпорт/Експорт**: Додано можливість зберігати локації у файли `.nbt` (`<world>/wavedefense/export/`) та переносити їх між серверами.
- **PacketHandler**: Методи відправки пакетів гравцям стали публічними для кращої взаємодії між модулями.

## [v0.2.9] — Розширення логіки тригерів та Магазину
### 🛠️ UI/UX та Редактор
- **Переписаний WaveTriggerEditorScreen**: 
    - Додано скрол списку тригерів та підтримку **AND-умов** (декілька обов'язкових умов для однієї хвилі).
    - Нові параметри: "Разово" та "Активувати з хвилі N".
- **Точка входу**: Додано можливість встановити окрему точку телепортації гравця при авто-активації локації.
- **Тригери магазину**: Додано умови появи товарів (`SHOP_WAVE_START`, `SHOP_PLAYER_HAS_ITEM` тощо).

### 🌀 Нова логіка Порталів та Предметів
- **Grace Period**: Після входу першого гравця в портал у інших є 30 секунд, щоб приєднатися, перш ніж він закриється.
- **PLAYER_HAS_ITEM**: Тепер можна налаштувати тригер на будь-який конкретний предмет через його registry id.
